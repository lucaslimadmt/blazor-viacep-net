# Consulta de CEP com Blazor

Projeto acadêmico desenvolvido com **C#**, **.NET 10** e **Blazor WebAssembly** para consultar endereços pela [API ViaCEP](https://viacep.com.br/).

## Funcionalidades

- Consultar um endereço informando seu CEP.
- Mostrar os dados retornados pela API em uma tabela.
- Exibir mensagens quando o CEP é inválido ou não é encontrado.

## Tecnologias

C#, .NET 10, Blazor WebAssembly, HttpClient e Bootstrap.

## Como executar

Com o [.NET SDK 10](https://dotnet.microsoft.com/download/dotnet/10.0) instalado, execute na pasta do projeto:

```bash
dotnet restore
dotnet run
```

Abra o endereço local informado no terminal. A consulta requer conexão com a internet.
